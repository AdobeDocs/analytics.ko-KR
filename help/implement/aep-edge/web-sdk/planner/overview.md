# 웹 SDK 마이그레이션 플래너

웹 SDK 마이그레이션 플래너는 Adobe Analytics 태그 확장을 Adobe Experience Platform 웹 SDK으로 마이그레이션하는 작업을 계획하고 실행하는 데 도움이 됩니다. Adobe Experience Platform 데이터 수집 내의 단일 안내 작업 공간으로 마이그레이션을 가져오므로 기존 태그 구현에서 체계적이고 추적 가능한 방식으로 웹 SDK으로 이동할 수 있습니다.

>[!AVAILABILITY]
>
>도구와 설명서 모두 현재 개발 중입니다. 설명서 가용성은 2026년 9월 말로 타깃팅됩니다.
